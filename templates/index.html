📌 About This Project

The Smart Diabetes Risk Assessment project is a machine learning-based application designed to predict diabetes using patient health information. It processes input data through preprocessing techniques and uses a trained Random Forest model to generate a prediction.


Machine Learning Algorithms Used:

Random Forest Naive Bayes K-Nearest Neighbors Support Vector Machine

Technologies: Python, Flask, Pandas, NumPy, Scikit-learn and Machine Learning.
